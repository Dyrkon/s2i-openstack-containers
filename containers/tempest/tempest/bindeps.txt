# NOTE: python3-cryptography is intentionally NOT installed via RPM here.
# The el10 RPM ships cryptography 49.x, but pyOpenSSL 24.2.1 (pinned by
# OpenStack upper-constraints) requires cryptography<44. Installing the RPM
# causes two .so files to coexist (_rust.abi3.so from pip 43.x and
# _rust.cpython-312.so from RPM 49.x); Python 3.12 prefers the cpython-312
# variant, which lacks symbols the pip 43.x Python code expects (e.g.
# check_ansix923_padding), producing an ImportError at runtime.
# pip manages cryptography 43.x exclusively, keeping the .so and Python
# files in sync. Remove this note and re-add python3-cryptography once
# pyOpenSSL is updated to >= 25.0 (which drops the cryptography<44 cap).
